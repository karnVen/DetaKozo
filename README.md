## ⚙️ Setup & Compilation

### C++ Compiler (GCC / MinGW)

To compile and run any C++ file in the repository:

```bash
# Compile with C++17 standard and optimizations/warnings
g++ -std=c++17 -Wall -Wextra -O2 <filename>.cpp -o <filename>

# Run executable (Windows)
./<filename>.exe

# Run executable (Linux / macOS)
./<filename>
```
